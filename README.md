# Project 19: Health Records System (AETNAVAULT EHR)

Sovereign electronic health record (EHR) and clinical compliance management platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Sterile Clinical UI**: Crisp white and soft-green clinical palette (`#f0fdf4`, `#166534`, `#15803d`, `#22c55e`), clean structured data tables, and high-visibility alert headers.
- **Role-Based Perspectives**: Instant toggle between Physician Charting and Patient Self-Service portals.
- **Clinical Encounter SOAP Logging**: Document consultations with ICD-10 diagnostic coding.
- **Cryptographically Signed E-Prescriptions**: Active medication schedule with digital doctor signature hash validation.
- **Structured Diagnostic Lab Panels**: CMP-14 biochemical profiles and cardiovascular subfractions with reference intervals.
- **Immutable HIPAA Audit Trail**: Real-time logging of all EHR reads, updates, and prescription sign events.
- **Patient Health Dossier Export**: Comprehensive PDF clinical extract generator simulation.

## Getting Started
```bash
npm install
npm run dev
```
